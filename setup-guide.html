Download & Start PocketBase
Single executable — no install, no Docker, no account needed

Download

Go to github.com/pocketbase/pocketbase/releases and download the latest pocketbase_*_windows_amd64.zip. Extract it — you get a single pocketbase.exe.

Put it somewhere easy, e.g. C:\pocketbase\pocketbase.exe

Start the server

Open PowerShell in the folder containing pocketbase.exe and run:

.\pocketbase.exe serve
✓ PocketBase is running at http://127.0.0.1:8090
✓ Admin UI is at http://127.0.0.1:8090/_/
First run: PocketBase will ask you to create a superuser (the PocketBase admin, not your app user). Set any email + password — you'll use this to manage collections.

Create Collections & First Admin User
Open the PocketBase admin UI and set up your database schema

Open http://127.0.0.1:8090/_/ → login with the superuser you just created.

Collections to create

Go to Collections → New collection for each row below:

Add admin_role to the users collection

Collections → users (the built-in auth collection) → Edit → Add field:

Field name: admin_role Type: Text Required: No

Create your first admin user

Collections → users → New record button (top right):

FieldValue

admin_rolesuper_admin
Valid admin_role values:   super_admin   content_manager   translator   analytics_viewer
3
Run the Admin Panel
Next.js 14 content management panel — runs at localhost:3001

Open a new PowerShell window and run:

# Navigate to admin app cd C:\DataFolder\my_a\child_apps\apps\admin # Create .env file Copy-Item .env.example .env # Install dependencies npm install # Start dev server npm run dev

The .env already has the right value — no changes needed:

NEXT_PUBLIC_PB_URL=http://127.0.0.1:8090
✓ Admin panel running at http://localhost:3001
✓ Login with the email + password you created in Step 2
4
Run the Mobile App
Expo + React Native — run on your phone via Expo Go app

Find your machine's local IP

The phone cannot use localhost — it needs your PC's LAN IP.

ipconfig

Look for IPv4 Address under your Wi-Fi adapter, e.g. 192.168.1.5

Phone and PC must be on the same Wi-Fi network for Expo Go to connect.

Set up and start

# Navigate to mobile app cd C:\DataFolder\my_a\child_apps\apps\mobile # Create .env file Copy-Item .env.example .env

Edit .env — replace the IP with yours:

EXPO_PUBLIC_PB_URL=http://192.168.1.5:8090
# Install dependencies npm install # Start Expo (shows a QR code) npx expo start

Scan the QR code with the Expo Go app on your phone. The app will open.

For Android emulator instead of a real phone

# Use localhost since emulator shares host network # Set in .env: EXPO_PUBLIC_PB_URL=http://10.0.2.2:8090 npx expo start --android
Android emulator note: Use 10.0.2.2 instead of localhost or 127.0.0.1 — that is the emulator's alias for the host machine.
✓ Login screen appears on your phone
✓ Sign in using the same admin@… credentials from Step 2
✓ Or create a new regular user: PocketBase UI → users → New record (leave admin_role empty)

Quick Troubleshooting
ProblemFix
Admin panel shows blank / can't fetch stories Make sure PocketBase is running in terminal 1. Check http://127.0.0.1:8090/api/health
Mobile app can't connect to backend Use your machine's LAN IP in .env, not localhost. Both devices on same Wi-Fi?
Login says "unauthorized" Make sure the user record has admin_role = super_admin in PocketBase users collection
npm install fails with missing package You're on Node 20+? Run node --version to check
Stories not showing in mobile app Stories must have status = "published". Check in PocketBase UI → stories collection
